# ADR-0001: Миграция на OpenAI Responses API

## Статус

Accepted (2026-02-07)

## Контекст

Плагин использовал Chat Completions напрямую из монолитного обработчика события. Это осложняло тестирование, поддержку и эволюцию.

## Решение

- Использовать `Responses API` как единственный API-слой.
- Оставить пользовательский UX и ids настроек обратно-совместимыми.
- Вынести API-клиент, конфиг и presenters в отдельные модули.

## Последствия

Плюсы:

- Более современный API-путь для новых интеграций.
- Четкие границы модулей и упрощенная тестируемость.
- Единая обработка ошибок и безопасные логи.

Минусы:

- Необходимость поддержки fallback-парсинга структуры `output`.
- Небольшой рост количества файлов и инфраструктуры.
